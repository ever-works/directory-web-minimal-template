React UI Components is a curated directory of React component libraries. It helps you compare the options for a new project by category, by tag and side by side.

## What We Cover

- Headless libraries that give you behavior and accessibility without styles
- Styled component suites with a complete design system
- Specialized libraries for forms, tables and animation

## How We Curate

- Every library is actively maintained and open source.
- We check accessibility support and TypeScript types before listing a library.
- Listings are reviewed when a library ships a major release.
